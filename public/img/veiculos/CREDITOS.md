# Créditos das imagens de veículos

As imagens em 3D desta pasta vêm do projeto **Microsoft Fluent Emoji**:

- Repositório: https://github.com/microsoft/fluentui-emoji
- Licença: MIT (Copyright (c) Microsoft Corporation)
- Formato: PNG transparente, 256 × 256 pixels
- Arquivos usados: `delivery_truck.png`, `articulated_lorry.png`,
  `minibus.png`, `pickup_truck.png` e `package_3d.png`

As imagens foram copiadas para o próprio site para manter a CSP em `'self'`.
Nenhuma imagem é carregada de CDN externa.
